# Picture Blast Solitaire

`Picture Blast Solitaire`는 Vertex AI 기획 세션 내용을 바탕으로 정리한 continuation-ready 저장소입니다. 그림 퍼즐과 솔리테어 감각을 결합한 하이브리드 퍼즐을 HTML5에서 먼저 검증하고, 이후 Godot/Unity용 상용 퍼즐 구조로 옮기기 쉽게 구성했습니다.

## 포함 내용

- `web-prototype/index.html`: 단일 파일 하이브리드 퍼즐 프로토타입
- `docs/GAME_DESIGN_SPEC.md`: 5x5 메인 + 3x3 보스 퍼즐 구조
- `docs/LEVEL_SAMPLE.json`: 보스 스테이지 샘플 데이터
- `docs/TECH_NOTES.md`: 이미지 업로드, 사운드/햅틱, 세이브 확장 포인트
- `src-concept/scene_map.md`: 후속 엔진 씬/서비스 분리 메모
