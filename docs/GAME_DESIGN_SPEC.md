# Game Design Spec

2026-11-17 사용자 정정으로 드래그 교환·세로 완성·낙하 게임으로 확정했습니다. 최신 기준은 `docs/PICTURE_SWAP_SPEC.md`입니다. 현재 실행 코드는 이전 클릭 제거 방식이며 수정 대기 중입니다. 숫자 ±1 프로토타입은 legacy-solitaire.html에 보존합니다.

## 장르와 코어 루프

- 그림 조각을 보고 맞는 두 조각을 찾아 하나의 그림으로 완성하는 캐주얼 퍼즐.
- 보드 어느 위치든 카드끼리 드래그로 교환합니다. 빈칸 이동은 금지합니다. 같은 artId의 top 바로 아래 bottom이 오면 제거하고 열별로 아래로 내려 연쇄를 처리합니다.
- 첫 검증판은 화병 6종, 12장(3열×4행), 제한 시간 없이 시작합니다. 열마다 짝수 장이어야 끝까지 비울 수 있습니다.
- 완성한 쌍과 전체 목표를 보여주고 판을 비우면 다음 스테이지로 이동합니다.
- 메인과 보스는 동일한 짝맞추기 규칙을 사용하며 보드 크기가 다릅니다.
- 기존 숫자 ±1/중앙 카드/Draw/reveal 방식은 레거시 프로토타입으로 보존합니다.
