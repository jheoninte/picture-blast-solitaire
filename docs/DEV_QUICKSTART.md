# DEV QUICKSTART

## 목표

- 카드 규칙, reveal 시스템, 유저 이미지 파이프라인을 분리해 바로 기능 개발 가능한 상태를 만듭니다.
- 후속 엔진 이식 시에도 레벨 데이터와 규칙 데이터가 그대로 쓰이도록 유지합니다.

## 실행

```bash
npm install
npm run dev
```

## 추천 첫 작업 순서

1. 카드 이동 규칙과 reveal 진척도 계산을 분리합니다.
2. `docs/LEVEL_SAMPLE.json`을 기반으로 스테이지 로더를 분리합니다.
3. 사용자 이미지 업로드를 메모리 참조/세이브 참조 구조로 나눕니다.
4. 메인 퍼즐과 보스 퍼즐을 공용 규칙 엔진에 연결합니다.

## 첫 스프린트 산출물

- 카드 규칙 모듈화
- 스테이지 데이터 파서
- 세이브 슬롯 구조 초안
- UI 상태와 퍼즐 상태 분리
