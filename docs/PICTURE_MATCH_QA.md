# 그림 짝맞추기 검증 기록

> 아래는 사용자 의도와 다른 이전 클릭 제거 방식만 검증한 역사 기록입니다. 드래그 교환·세로 완성·낙하 규칙의 QA는 아직 수행하지 않았습니다. 최신 기준은 PICTURE_SWAP_SPEC.md입니다.

2026-11-17, Windows 웹 프로토타입 기준.

- Gemini 제공 Node assert와 저장소 check 통과. 레거시 6개 해 경로/아트 대응 검사 유지, 새3개 판 해 경로와 PNG12장 헤더·128×176 크기 확인.
- 확장 검사: 2,016개 카드 조합, 복사본 교차 매칭, 입력 불변성, 선택/해제/불일치, 전 레벨 클리어, 힌트 비파괴성, 360개 섞기·저장 왕복과 제거된 빈자리 보존.
- 잘못된 레벨/아트 경로/저장 순열·제거 기록 거부, 이미지 로딩 실패, 손상/미래/과대 저장, 접근 거부, 직렬 쓰기·오류 후 재시도, 레거시 키 보존 확인.
- 실제 브라우저: 12장→24장→36장 플레이/전체 완료, 섞은 카드 위치 새로고침 복원, 그림12종 조각 로딩, 완료 복원.
- 빠른 입력 중 카드 재생성과 미리보기의 레이아웃 이동으로 클릭이 빠지는 문제를 발견해 수정. 카드 DOM 재사용과 위치 고정 미리보기 적용 후 36장 전체를 연속 클릭하여18쌍 완료 재검증.
- 375×812에서 36장 그림과 하단 도구 표시, 가로 넘침 없음. 데스크톱에서도 가운데 세로형 화면과 실제 이미지 표시 확인.
- build와 모듈 구문/공백 검사 완료. 아트는 개발 참고 자료이며 상업용 사용 권한 확보/최종 아트 제작은 별도입니다.

이 검증은 iOS SDK/실기기, 출시용 아트, 상점/결제/광고, 재미와 리텐션 검증을 포함하지 않습니다.
